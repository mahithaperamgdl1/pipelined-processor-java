# Coursework submissions

The submitted archives and lab reports for the IIT Dharwad Computer
Architecture course that this simulator was built for.

The lab archives are successive snapshots of the **same** codebase that
lives at the root of this repository — each one is that week's state of
the simulator, not a separate project. `cs24bt054_Lab6.zip` contains
exactly the 32 source files under `src/`, so the repository root is
the Lab 6 submission with a README and tests added.

| Submission | Archive | Report |
|---|---|---|
| Assignment 1 (RISC-V assembly: fibonacci, prime, palindrome, even-odd, descending) | `CS24BT054_assignment1 (2).zip` | `CS24BT054_assignment1_partA.pdf` |
| Assignment 2 (instruction parsing and simulator skeleton) | `cs24bt054_assignment2 (2).zip` | — |
| Lab 3 (basic pipeline stages) | `cs24bt054_lab3.zip` | `report_lab3.pdf` |
| Lab 4 (data hazards and stalling) | `cs24bt054_lab4 (1).zip` | `lab4 report.pdf` |
| Lab 5 (event-driven memory system) | `cs24bt054_lab5 (3).zip` | `lab5_CA_report.pdf` |
| Lab 6 (set-associative cache with LRU) | `cs24bt054_Lab6.zip` | `CA_LAB6.pdf` |

They are kept zipped because the snapshots overlap almost entirely with
each other and with `src/`; unpacking them would bury the working
simulator under five near-identical copies.
